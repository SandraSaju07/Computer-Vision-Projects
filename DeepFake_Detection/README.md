# DeepFake Detection System 🎭

This project detects whether a given video is real or fake using a deep learning model. It processes the video frames, extracts features using InceptionV3, and classifies them using a GRU-based sequence model.


## Usage

1. **Install Dependencies**
```
pip install -r requirements.txt
```
2. **Train the Model**
```
python train_model.py
```
3. **Run the App and Predict the Model**
```
python app.py
```
